# Kim Ngân — Graduation Invitation

Static graduation invitation website.

## Structure

- `index.html` — main page
- `styles.css` — compiled Tailwind and custom styles
- `guests.js` — guest personalization
- `images/` — photos and Open Graph preview
- `src/styles.css` — Tailwind source styles
- `tailwind.config.cjs` — Tailwind theme
- `vercel.json` — Vercel static-site and cache configuration
